# Cite Cellucid from the app

**Audience:** anyone writing a paper, a thesis or a report with Cellucid  
**Time:** 1 minute

The reference to cite is one click away in the app itself, so you never have
to look it up.

## Where it is

1) Scroll the left sidebar to its foot (collapse the open sections, or scroll
   past them). The footer's second line reads **Docs · Cite · GitHub ·
   Privacy · Terms**.
2) Click **Cite**. The **Cite Cellucid** dialog opens over the app; nothing
   about your data or view changes.

## What it gives you

- **The reference**, formatted for a reference list, read from the
  `CITATION.cff` the site is published with: the dialog is never out of date
  with the citation the project asks for.
- **BibTeX** for the same reference, below it.
- **Copy reference** and **Copy BibTeX** copy either one to the clipboard (the
  button reads **Copied** for a moment).
- While the preprint has no DOI, a line above the reference says it is a
  **Placeholder**; the reference changes when the preprint is published.
- The dialog's **i** says when to cite it (the web app, the Python package or
  the R package) and links to how to cite a built-in sample's own study.

Close it with **×**, {kbd}`Escape`, or a click outside it.

If the citation cannot be read (no network after the page loaded, for
example), the dialog says so and links to {doc}`../../../citing`, the same
reference on this site.

## Also cite

- **A built-in sample dataset**: the study it came from
  ({doc}`../b_data_loading/12_sample_dataset_provenance`).
- **Your own dataset's source**: the citation shown in the **Dataset** box,
  when the file names one.
- **The version**: the footer's last line, **Version** and **Build**. The
  history's methods paragraph (**State › History** menu, see
  {doc}`../m_state_history/04_tour_methods_and_report`) writes the version and
  a `[citation]` place for this reference into a ready-made methods text.
